# Controlled React Form

This project is a simple React application that demonstrates the use of controlled components in forms. It allows users to input their username and favorite technology, with real-time updates displayed below the form.

## Features

- Controlled form inputs for Username and Favorite Technology.
- Real-time preview of the entered data.
- Simple and clean user interface.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (version 14 or later)
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/controlled-react-form.git
   ```

2. Navigate to the project directory:
   ```
   cd controlled-react-form
   ```

3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the application, run the following command:
```
npm start
```

This will launch the app in your default web browser at `http://localhost:3000`.

### Built With

- React - A JavaScript library for building user interfaces
- CSS - For styling the application

## Usage

- Enter your username in the designated input field.
- Select your favorite technology from the input field.
- The entered data will be displayed in real-time below the form.
